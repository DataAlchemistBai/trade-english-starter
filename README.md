# Trade English Starter · 外贸英语入门

[手机／电脑直接使用](https://dataalchemistbai.github.io/trade-english-starter/)

基于 [British Speaking Studio](https://github.com/DataAlchemistBai/british-speaking-studio) 的独立成人初级版本。原站不改动，浏览器进度和缓存也使用独立命名空间。在线使用不需要登录、安装软件或配置 API 密钥。

## 两个学习区

- **外贸入门：12 节短课**。第 01–06 节涵盖公司介绍、产品目录、颜色尺寸、价格数量、样品和发货。第 07–12 节练习最低起订量、库存与替代款、数量折扣、订单确认、发货延误和漏发补寄。包含服装、家居和五金等产品情景。
- **故事进阶：36 张原版卡片**。保留六位虚构成年人物、原对话及关系线。包含男同性恋约会、友情和工作等非露骨成人社交情景，不是外贸教材。

新课中人物进行客户／供应商角色扮演，不改变原故事的职业或关系。价格、交期与地址都是教学情景，不构成真实交易条件。

## 播放与逐词学习

- 首次打开默认 **0.65×**，可选 0.85×、1.0×、1.1×；保持音高。
- 两个区都带**真实词级语音时间标记**，不是按字数平均估算。单词和整句分别高亮，完整英文始终可见。
- 点击句子定位；尚未加载时保留最后选择，等音频和时间轴就绪后再跳转。若手机浏览器要求手动启动音频，点击播放按钮即可。
- 单句循环、字幕跟随、中文释义、英文专注、明暗主题和说话人物高亮。
- 每节入门课 6 个重点词，提供中文、音标、例句和原音片段。点击喇叭会播放该词在本课中的录音，不使用手机系统语音。
- 词汇“认识”标记与播放进度保存在当前浏览器，音频／图片／时间轴按使用情况缓存。
- 双人和四人照片沿用原尺寸规则；四人采用 2×2 布局。

为匹配准确词级标记，进阶区音频在本版本中以原文、原声线配置和 `-8%` 参数重制；原站的录音没有覆盖。`130wpm` 是历史文件名，不表示固定实测词速。

## 本地运行

Node.js 18+，不需要安装 npm 依赖：

```sh
npm start
```

打开终端地址。不要使用 `file://` 双击网页，因为读取课程和本地缓存需要 HTTP／HTTPS。附带静态服务器仅供本地开发，支持音频 Range 请求。

```sh
npm test
```

检查 48 张卡片、全部词级标记、重点词音频定位、逐词文本重建和不同倍速下的媒体时间查找。浏览器端交互及窄屏还应另做实测。

## 文件

```text
index.html / styles.css / starter.css  页面与保留的视觉基础
app.js / logic.js                     播放器、逐词高亮、定位与数据校验
trade.json                            12 节基础外贸课与重点词
advanced.json                         36 张原故事与背景
characters.json                       人物、音色说明和显示裁切框
base-vocabulary.json                  进阶故事可用的基础词汇
audio/                                48 段对应录音
timings/                              48 份句级＋词级真实时间标记
images/                               原人物 AI 图片及历史版本
practice-cache-sw.js                  独立缓存，仅管理本版本命名空间
docs/STORY_NOTES.md                    原故事连续性档案
```

单词的 `start/end` 是媒体文件中的秒数；`charStart/charEnd` 对应句子中的字符位置。前端直接读取 `audio.currentTime`，不再乘播放倍速，因此变速、跳句和循环共用同一时间轴。服务偶尔把极短弱读词的持续时间标为零，此时用下一个真实单词起点作为结束边界，并以 `endSource` 注明；不按字数分摊时间。
